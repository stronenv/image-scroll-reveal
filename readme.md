## Description

The Image Scroll Reveal block allows you to create engaging image comparison experiences that respond to user scrolling. Display two overlapping images where the top image gradually reveals the bottom image as users scroll down the page.

Perfect for:
* Before and after comparisons
* Product reveals
* Portfolio showcases
* Interactive storytelling
* Design transformations

Key Features:
* Smooth scroll-triggered animations that start when the block enters the viewport
* Four reveal directions: left, right, top, and bottom
* Customizable fade transition width for smooth blending
* Adjustable fade effect styles
* Full WordPress image block settings support (alt text, dimensions, borders, spacing, links)
* Responsive design that maintains aspect ratios
* Easy-to-use editor interface with drag-and-drop image uploads

The animation begins automatically when the block enters the viewport and completes when it reaches 30% from the top of the screen, creating a natural and engaging user experience.

## Installation

1. Upload the plugin files to the `/wp-content/plugins/image-scroll-reveal` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Add the "Image Scroll Reveal" block to any post or page
4. Upload your top and bottom images
5. Customize the reveal direction and fade settings in the block sidebar

## Frequently Asked Questions 

### How do I change the reveal direction?

In the block sidebar settings, you'll find a "Reveal Direction" option with four choices: Left, Right, Top, and Bottom. Select your preferred direction to change how the top image reveals the bottom image.

### Can I adjust the fade effect?

Yes! The block includes a "Transition Fade Width" setting where you can specify the width of the fade effect in pixels. You can also choose different fade effect styles for various visual appearances.

### Will this work on mobile devices?

Absolutely! The block is fully responsive and works smoothly on all devices. The images automatically adjust to maintain their aspect ratios on different screen sizes.

### Does the animation affect page performance?

The animation is optimized for performance and uses efficient scroll event handling with throttling to ensure smooth scrolling without impacting page performance.

## Advanced Usage

The block supports all standard WordPress image settings including:
* Alt text for accessibility
* Custom dimensions (width and height)
* Border styles and colors
* Spacing controls (margin and padding)
* Link options to connect images to URLs

For best results, use images with the same dimensions or aspect ratios to ensure smooth transitions.
